# Photon Quantum 3 Twin Stick Shooter 3.0.9 as a MOBA foundation: contents, architecture, licences, Bot SDK

Research date: 2026-10-08. Scope: the official Quantum 3 "Twin Stick Shooter" sample (zip `quantum-twinstickshooter-3.0.9.zip`, imported in `game/`), the licences that govern redistributing a game built on it, Bot SDK availability, and whether a closer official sample exists.

Tags used on every claim: **VERIFIED** (read on the cited page or in the cited local file), **INFERRED** (deduced from verified facts), **UNKNOWN** (not found).

Method note: `doc.photonengine.com` and `itch.io` block the generic fetcher (Gcore "browser validation" page, HTTP 403). Photon docs, Photon terms, OpenGameArt and GitHub were read with `curl` plus browser headers; the three itch.io pages and the `/terms` index were read in the user's Chrome. Local files were read from `game/` and from the original zip (`unzip -Z1`, `unzip -p`).

## KQ1. What the official sample contains and how it is architected

### Takeaway
The sample is a free, public, deterministic Quantum 3.0.9 project (Unity 2021.3.30f1 on the page, migrated locally to 6000.6.4f1) that ships full source for a top-down 2-team shooter with 3 heroes x 2 skills, Bot SDK HFSM bots, room filling and player replacement by bots, an AI Director for team strategy, data-driven sensors and tactics, line of sight, bush invisibility, a custom top-down 2D KCC, navmesh steering and mobile on-screen controls. The gameplay rules (Coin Grab, two skill slots, coin-driven strategies) are a thin layer over a generic character/skill/attack/attributes/health/respawn/team framework.

## KQ2. What the Photon sample licence permits for a distributed, possibly commercial game

### Takeaway

## KQ8. Unity WebGL and the Bot SDK

### Takeaway
No documented incompatibility was found. Photon's own evidence is indirect: the Twin Stick Shooter page (whose bots are Bot SDK HFSM agents) states the game "can be exported for web platforms" and embeds a browser build, and the WebGL manual lists only general Quantum constraints. The project's own WebGL build of the sample with bots is recorded in `docs/STATUS.md`.

### Cited Findings
- Twin Stick Shooter page: "This game can be exported for web platforms. Test it directly in your browser:" with an embedded "Play / Quantum Twin Stick Shooter". VERIFIED. [Source](https://doc.photonengine.com/quantum/v3/game-samples/twin-stick-shooter)
- WebGL manual: "Quantum supports multiple platforms, including WebGL"; Release mode + IL2CPP recommended; "Older versions of Unity only support single-threading in WebGL builds ... Starting with Unity 6, multithreading was introduced as an experimental feature"; LTO stripping issue needs latest 3.0/3.1 SDK + `com.unity.sharp-zip-lib`; LUT files as Addressables with `QUANTUM_ENABLE_ASYNC_LUT_LOADING`; WebSockets over TCP, "it is recommended to also offer the game as a download"; more WebGL demos at https://photonengine.itch.io/. No mention of Bot SDK. VERIFIED. [Source](https://doc.photonengine.com/quantum/v3/manual/webgl)
- Bot SDK overview and release history contain no WebGL statement (grep of the page text). VERIFIED absence. [Source](https://doc.photonengine.com/quantum/v3/addons/bot-sdk/overview)
- Project evidence (`docs/STATUS.md`, 8 Oct 2026): a WebGL build of the sample's Gameplay scene with bots under Unity 6000.6.4f1 produced 22,193,639 bytes with zero build errors and ran in headless Chrome (menu with three heroes, then a match after Start); the user reports it runs on a Redmi 11C "assez fluide" with some lag; no frame rate was measured. VERIFIED (local file; this is the project's own record, not Photon's).
- Web search for "Quantum 3 Bot SDK WebGL" returned only the separate Bot SDK and WebGL pages, nothing linking the two. VERIFIED (search result).

### Inferences
- Bot SDK code is ordinary deterministic simulation C# plus one managed DLL (`Quantum.BotSDK.Core.dll`, dependency on UnityEngine removed in 3.4.6), so IL2CPP/WebGL builds have no special requirement beyond Quantum's own (keep `[Preserve]` attributes on systems, which the sample already does). INFERRED.
- The "Quantum Crazy Starter WebGL" technical sample is Circle-only, so Photon's dedicated WebGL starter is not available on the free plan. INFERRED from the nav "Circle" marker.

### Gaps
- No Photon statement, forum post or changelog entry explicitly covering Bot SDK on WebGL was found. UNKNOWN.
- Mobile browser performance of the HFSM bots on the target device is not measured anywhere (project STATUS says so). UNKNOWN.
