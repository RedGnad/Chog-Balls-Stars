**Ce qui ne doit pas devenir une preuve.** Un chiffre de followers ne donne pas les joueurs actifs ; une adresse ne donne pas une personne ; un volume NFT ne donne pas une demande de jeu ; une publication récente ne garantit pas sa validité ; un agent crédible ne garantit pas un jeu plaisant ; l'absence d'un concurrent dans ces recherches ne prouve pas la nouveauté.

Les recherches ont porté sur le brief et les sites Chog, les références aux personnages NFT et à leur progression, l'IA dans l'expérience de jeu, la motivation, la contribution communautaire et les systèmes déjà présents sur le GitHub partagé. Les sources agrégées, annonces reprises sans vérification, estimations de trafic et commentaires isolés n'ont pas été utilisés pour estimer une demande ou classer les concepts. Une enquête primaire est nécessaire pour décider.
